# Satryn AI (marketing) website

AI our way. This repo contains the Satyrn AI marketing website. it uses Zensical as static site generator (SSG)

## Usage

This project is created using `uv` which can also be used to install and use `zensical`. To run the development
server, execute:

```bash
uv run zensical serve
```

To build the site for production run
```bash
uv run zensical build
```
