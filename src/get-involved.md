Satyrn is built by the people who use it. You don't need to write code to be
useful here.

## Start on GitHub

Everything lives at [github.com/satyrn-ai](https://github.com/satyrn-ai) — the
code, the issues, and the arguments about what to build next.

!!! warning "Still being written"

    There is not a good-first-issue list or a chat invite yet. Until there is,
    an issue on GitHub is the most reliable way to reach us.

## What actually helps

Use it and tell us what broke. At this stage that's worth more than almost
anything else. Bug reports from real work are hard to fake and easy to act on.

Fix the docs. If something took you an hour to figure out, that hour was a
documentation bug. Write down what you wish you'd read.

Write code. Pick up an open issue, or open one first if you'd rather argue
about the approach before building it.

Tell someone. A community-owned project only works if the people who'd want it
can find it.

## How decisions get made

In public, on GitHub. The reasoning behind a change should still make sense to
someone reading it a year later, which is most of why we keep it out in the
open.
